 ТЕХНИЧЕСКОЕ ЗАДАНИЕ: Моделирование интерференции и когерентности (v2.0)

 1. Входные параметры и интерактивное управление
| Параметр | Тип | Описание | Диапазон |
|----------|-----|----------|----------|
| N_src | int | Кол-во источников в плоскости z=0 | [1; 10] |
| x_src | float[] | Вертикальные координаты центров источников | [-0.1; 0.1] м |
| λ_i | float[] | Длина волны каждого источника | [400e-9; 700e-9] м |
| E0_i | float[] | Амплитуда поля | [0.1; 1.0] отн. ед. |
| φ0_i | float[] | Начальная фаза | [0; 2π] рад |
| Δλ | float | Полуширина спектра (0 → монохроматический) | [0; 50e-9] м |
| W_src | float | Ширина протяжённого источника | [0; 0.05] м |
| z_trans | float | Плоскость транспаранта | [0.01; 1.0] м |
| x_slit | float[] | Координаты центров щелей | [-0.1; 0.1] м |
| w_slit | float | Ширина щели (геометрическая обрезка) | [1e-6; 1e-3] м |
| z_screen | float | Плоскость экрана наблюдения | [0.1; 2.0] м |
| dt_emit / dt_anim | float | Период эмиссии / шаг анимации | [0.5; 3.0] / [0.016; 0.05] с |

Интерактивное размещение (мышь):
- Клик по оси x при z=0 → создание/перемещение источника.
- Клик по оси x при z=z_trans → создание/перемещение щели.
- Drag & drop с визуальным курсором и snap-привязкой к сетке.
- Контекстное меню (ПКМ) → удаление элемента, точный ввод координат.
- Автоматическая валидация: запрет пересечения элементов, выход за границы сцены.

 2. Система координат и макет сцены

        ↑ x (вертикаль)
z=0     | z=z_trans        z=z_screen
[источники] → [щели/маска] → [экран]
        |        |                |
        |        |           [Картина интерференции]
        |        |              (Верхний правый угол)
        → z (горизонталь, направление распространения)

- Основная область: ~70% ширины окна. 2D-сечение x-z плоскости.
- Верхний правый угол: фиксированный прямоугольник (300×200 px) с 2D-картой интенсивности I_norm(x). Обновляется в реальном времени.
- Нижняя панель: горизонтальный контейнер с ползунками (кастомные, с закруглениями, зелёный бегунок, плавные переходы 150ms).

 3. Физические ограничения и алгоритм
- Дифракция запрещена. Щели → идеальные точечные вторичные источники. За пределами щелей E=0. Только геометрическая обрезка.
- Временная когерентность: γ_t(Δr) = exp(-π·(Δr/L_c)^2), L_c ≈ λ²/Δλ.
- Пространственная когерентность: I(x) = ⟨|Σ U_i(x, x_s)|²⟩_s. Дискретизация W_src на M точек, усреднение интенсивностей.
- Расчёт поля (векторный):
  1. r_i = sqrt((z_screen)^2 + (x - x_i)^2)
  2. U_i(x) = (E0_i / r_i) · exp(-j·(2π/λ_i)·r_i + j·φ0_i)
  3. I(x) = mean(|Σ U_i·γ_t|²) по источникам и точкам W_src
  4. I_norm = I / max(I)
- Скалярное приближение, поляризация не учитывается.

 4. Визуализация и рендеринг
- Источники: Визуально отображаются как вертикальные отрезки ширины W_src. При N_src=1 волны математически излучаются из геометрического центра, но визуально показывается протяжённость для наглядности.
- Щели: Вертикальные линии/полосы на z=z_trans. Подсвечиваются при наведении. Доступны для клика/перетаскивания.
- Волновые фронты: Концентрические окружности, расширяющиеся с v_wave ~ 50-80 px/с. 
  - Цвет привязан к λ через CIE 1931 → RGB.
  - Прозрачность убывает как 1/√r (2D-сечение).
  - При пересечении z=z_trans фронты жёстко обрезаются по маске щелей. Дифракционные огибания не рисуются.
- Картина интерференции (верхний правый прямоугольник): 
  - 2D-теплокарта I_norm(x) по вертикали.
  - Минимумы → 000000, максимумы → насыщенный цвет λ.
  - Синхронное обновление с частотой 30-60 FPS.

 5. Архитектура и структура файлов
Проект разбит по принципу Single Responsibility. Изменение одного модуля не требует правки других.

project/
├── main.py                 Точка входа, инициализация QApplication
├── app_controller.py       Связка UI, физики и рендеринга. Управление таймерами
├── config/
│   ├── schema.py           Pydantic-модель параметров, валидация диапазонов
│   └── defaults.py         Значения по умолчанию, константы (c, ε0, π)
├── physics/
│   ├── propagation.py      Векторный расчёт r_i, U_i, затухание 1/r
│   └── coherence.py        Модули γ_t(Δr), усреднение по W_src, I_norm
├── renderer/
│   ├── scene_manager.py    Координатные преобразования (px ↔ м), масштабирование
│   └── wavefront_draw.py   Отрисовка сферических фронтов, цвета CIE, альфа-канал
├── ui/
│   ├── main_window.py      Макет окна, размещение панелей, верхний правый прямоугольник
│   ├── controls.py         Кастомные ползунки, стилизация QSS, анимации переходов
│   └── interaction.py      Mouse events, hit-test, drag&drop, создание/удаление элементов
├── utils/
│   ├── color_map.py        CIE 1931 → RGB конвертер
│   └── logger.py           Логирование расчётов и FPS
└── tests/
    └── test_physics.py     Автоматические проверки по ТЗ (кейсы 1-4)

- Зависимости: physics не знает про ui или renderer. ui передаёт параметры через config.schema. app_controller координирует потоки данных.
- Расчётные модули принимают/возвращают только numpy.ndarray.

 6. Технические требования
- Стек: Python 3.10+, numpy, PyQt6/PySide6, PyQtGraph (для графиков/полей), pydantic (конфиг).
- Производительность: 
  - Векторизация всех расчётов. Запрещены for по точкам экрана/источников.
  - Время расчёта кадра < 10 мс. При превышении → автоматическое снижение dt_anim или упрощение сетки.
- Анимация: QTimer с фиксированным интервалом. Физика вычисляется в основном потоке (т.к. векторизована и быстрая), рендеринг через pyqtgraph.ImageView/PlotWidget.
- Документация: Комментарии с номерами формул (билеты 7-9), requirements.txt, пример запуска python main.py.

 7. Тест-кейсы
1. Δλ=0, W_src=0, 2 щели → чёткие полосы Юнга, видность ≈ 1.0.
2. ↑Δλ → контраст падает к краям (временная когерентность).
3. ↑W_src → глобальное размытие, при W_src > λ·L_src/d полосы исчезают.
4. mask_type="none" → интерференция без щелей, корректная зависимость от z_screen.
5. Интерактивность: клик по оси создаёт элемент, перетаскивание меняет x_src/x_slit в реальном времени, удаление через ПКМ работает без крашей.
